# 🍕 NORTHSIDE PIZZA — 無料PWA版 Ver.48

**Ver.48のワンオペ調理ゲームをそのまま無料公開できる、PWA対応ファイル一式です。**
すでにPWAを公開している場合は、同じGitHub Pagesリポジトリのファイルを上書きしてください。

## Ver.48のゲーム内容

- Ver.48の注文数・注文ラッシュ・売上調整を反映
- スタッフなしのワンオペ、まとめ注文、日商ランキング、お客様満足度
- 11:00開店、LV1〜30は21:00閉店、LV31〜40は22:00、LV41〜100は23:00閉店
- 既存のレシピ、設備投資、店舗展開、演出を維持

## 初めて無料公開するとき（GitHub Pages）

1. https://github.com でアカウントを作る（すでにある場合はログイン）。
2. https://github.com/new で `northside-pizza` などの名前で **Public** リポジトリを作る。
3. リポジトリの **Add file → Upload files** を開く。
4. このZIPを **解凍** し、**中にある `index.html`, `manifest.webmanifest`, `sw.js`, `icons` フォルダなどをまとめてアップロード**。ZIP自体をアップロードしても公開されません。
5. 画面下の **Commit changes** を押す。
6. **Settings → Pages → Build and deployment** から Source=`Deploy from a branch`、Branch=`main` / `/(root)` を選び **Save**。
7. 数分後、同じ **Settings → Pages → Visit site** から公開URLを開く。

公開URLの例： `https://ユーザー名.github.io/northside-pizza/` （実際のURLはGitHubで確認）。
費用はGitHub Freeの公開リポジトリの利用範囲で0円。App Storeへの登録は不要です。

## すでに Ver.44 / Ver.45 などのPWAを公開している場合

1. **ゲームを開いて、セーブデータのバックアップをファイル保存**してください。
2. GitHubの**同じリポジトリ・同じブランチ**で `index.html`・`sw.js`・`manifest.webmanifest`・`icons/` を新しいファイルに置き換えます。
3. 同じ公開URLを開き直すとVer.48になります。古い画面が残る場合は、アプリを一度終了して開き直すか、インターネット接続中に再読み込みしてください。キャッシュの切り替わりには短時間かかる場合があります。
4. **セーブデータは従来のlocalStorageキーを維持**しているため、同じ公開URL・同じ保存領域なら基本的に続きからプレイできます。ただしバックアップ推奨。

⚠️ **リポジトリ名や公開URLを変更すると、セーブの保存領域が変わる**ことがあります。既存のURLを維持してください。

## iPhoneでアプリ風に遊ぶ

1. iPhoneの **Safari** で公開URLを開く。
2. 共有メニューから **ホーム画面に追加**。
3. **Webアプリとして開く** を有効にして **追加**。
4. ホーム画面のNORTHSIDEアイコンをタップして起動。

AndroidではChromeのメニューから **アプリをインストール／ホーム画面に追加** を選びます。
一度オンラインで読み込んだあと、ゲームのファイルが端末に保存されていればオフラインでも起動できます（端末の保存領域やブラウザ設定によってはキャッシュが消える場合があります）。

## セーブデータ・オフラインの注意

- セーブデータは **プレイヤー本人の端末内** に保存され、公開サーバーには送信しません。オンラインランキング共有機能はありません。
- Safari内で開いたページと、ホーム画面に追加したWebアプリでは、保存領域が分かれる場合があります。
- 旧HTMLファイルから新PWAへ移るときは、元のゲームの **バックアップ／復元** 機能を使ってください。
- ブラウザ履歴・Webサイトデータ・ホーム画面アプリを削除するとセーブが消える可能性があります。
- 本ZIPは**公開用ファイル**であり、まだGitHubに自動アップロードされていません。公開URLはまだ発行されていません。
- Publicリポジトリのゲームソースコードは一般に閲覧可能です。
